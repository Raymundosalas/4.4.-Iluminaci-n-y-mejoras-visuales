# Helix Jump - Iluminación y Niveles en Unity

## Descripción

Este proyecto consiste en el desarrollo de un videojuego tipo Helix Jump en Unity, donde se implementa un sistema de niveles junto con mejoras visuales e iluminación para optimizar la experiencia del jugador.

## Funcionalidades

* Sistema de cambio de niveles
* Reinicio automático al perder
* Detección de fin de nivel
* Iluminación dinámica por nivel
* Efectos visuales (partículas y trail)
* Rotación de plataformas

## Iluminación

Se utilizó:

* Luz direccional para iluminación general
* Iluminación ambiental para mejorar visibilidad
* Cambio de colores según el nivel
* Skybox dinámico

## Mejoras visuales

* Efectos de partículas al impacto
* Estela de la bola (Trail Renderer)
* Colores dinámicos en plataformas

## Cómo ejecutar

1. Abrir el proyecto en Unity
2. Ir a Build Settings y verificar las escenas
3. Presionar Play

## Requisitos

* Unity Hub
* Versión recomendada: Unity 2021 o superior

## Conclusión

La implementación de iluminación y efectos visuales mejora la estética del videojuego, logrando una experiencia más clara y atractiva para el usuario.
